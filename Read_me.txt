Application de prédiction de prix des maison en californie (le repository est sur GitHub) et l'app est hébergée sur streamlit
---------------------------------------------------------------------------------------------------------------------
1- exécuter le code Jupyter en installant toutes les biblihotèques (cela va charger les pkl)
2-installez Joblib et streamlit sur votre environnement windows(en bash)
3- exécuter le fichier python app.py par (streamlit run app.py)
